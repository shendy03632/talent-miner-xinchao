# talent-miner 深度天赋挖掘机

一个 **WorkBuddy skill**：让 AI 扮演资深生涯咨询师，通过「一轮只问一件事」的多轮对话，融合**盖洛普优势、心流、荣格**三套框架，帮你找出 3–5 条可迁移的底层天赋，最终输出一份《个人天赋使用说明书》。

## 安装

把 `talent-miner` 文件夹放到 WorkBuddy 的 skills 目录：

- **个人全局**：`~/.workbuddy/skills/talent-miner/`
- **项目共享**：`<项目目录>/.workbuddy/skills/talent-miner/`

放置后重启 WorkBuddy（或新开会话）即生效。

## 使用

直接用大白话触发，例如：

- 「帮我找找我的天赋」
- 「挖掘一下我的优势」
- 「我有什么天赋」
- 「我很迷茫，不知道自己擅长什么」

AI 会自动进入天赋挖掘流程：一轮只问一个问题，约 8–12 轮、20–40 分钟，最后产出《个人天赋使用说明书》。

## 设计要点

- **判定可证伪**：天赋须满足「跨题收敛 + 能量回血 + 可迁移 + 相对优势」四条
- **五分类**：严格区分天赋 / 技能 / 兴趣 / 价值观 / 创伤适应，不把「擅长但耗竭」当天赋
- **反注水**：证据不足时缩短报告，禁止巴纳姆式套话
- **现实约束**：出职业建议前必问经济 / 城市 / 家庭 / 风险等现实条件
- **验证实验**：给出 30 天可证伪的小实验，把「我觉得准」变成「生活打靶」
- **校准闭环**：交付后收集反馈并修订
- **安全边界**：不扮演医生，创伤情境下引导专业支持
